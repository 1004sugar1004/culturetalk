# 💬 다문화 공감 톡

학생들이 다양한 인물과 1:1 채팅하면서 다문화 사회의 긍정적 효과와 문제점을 체험하는 교육용 웹 애플리케이션입니다.

## 📋 프로젝트 개요

이 프로젝트는 카카오톡 스타일의 채팅 인터페이스를 통해 학생들이 다양한 문화적 배경을 가진 5명의 이웃과 대화하며, 다문화 사회에서 발생하는 긍정적 효과와 문제점을 자연스럽게 학습할 수 있도록 설계된 교육 도구입니다.

실제 스마트폰처럼 보이는 UI와 키워드 기반 대화 시스템으로 학생들이 몰입감 있는 체험 학습을 할 수 있습니다.

## ✨ 주요 기능

### 현재 구현된 기능

1. **이름 입력 및 환영 화면**
   - 시스템 환영 메시지
   - 학생 이름 입력 기능
   - 개인화된 인사 메시지

2. **캐릭터 선택 화면**
   - 5명의 다양한 인물 프로필 표시
   - 각 인물의 배경 정보 (나이, 국적, 직업, 상황 설명)
   - 직관적인 카드 UI 디자인
   - 학생 이름이 반영된 환영 메시지

3. **1:1 채팅 인터페이스**
   - 카카오톡 스타일의 친숙한 채팅 UI
   - 실제 스마트폰 형태의 프레임 디자인
   - 실시간 메시지 전송 및 수신
   - 타이핑 인디케이터 (상대방이 입력 중일 때)
   - 메시지 타임스탬프 표시

4. **확장된 시나리오 기반 대화**
   - 키워드 기반 응답 시스템 (3단계 대화)
   - 각 캐릭터별 맞춤 시나리오
   - 단계별 대화 진행 (sequence 기반)
   - 학생 이름이 대화에 자연스럽게 포함
   - 각 캐릭터별 종료 인사 메시지

5. **추천 질문 기능**
   - 캐릭터별 맞춤 추천 질문 버튼
   - 학생 이름이 포함된 질문
   - 클릭 한 번으로 메시지 전송

6. **반응형 디자인**
   - 데스크톱: 스마트폰 프레임 스타일
   - 태블릿: 최적화된 프레임 크기
   - 모바일: 전체 화면 활용
   - 터치 인터랙션 최적화

## 🗄️ 데이터 구조

### Characters 테이블
- `id`: 캐릭터 고유 ID
- `name`: 이름
- `age`: 나이
- `nationality`: 국적
- `occupation`: 직업
- `description`: 설명
- `profile_image`: 프로필 이미지 (이모지)
- `background_color`: 프로필 배경색

### Messages 테이블
- `id`: 메시지 고유 ID
- `character_id`: 연결된 캐릭터 ID
- `sequence`: 대화 순서
- `sender`: 발신자 (character)
- `text`: 메시지 내용
- `trigger_keywords`: 트리거 키워드 배열

## 🚀 사용 방법

1. **웹사이트 접속**
   - index.html 파일을 브라우저에서 열기

2. **이름 입력**
   - 환영 메시지 확인
   - 자신의 이름 입력
   - "시작하기" 버튼 클릭

3. **캐릭터 선택**
   - 개인화된 환영 메시지 확인
   - 5명의 이웃 중 대화하고 싶은 인물 선택

4. **대화하기**
   - 자동으로 전송되는 인사 메시지 확인
   - 캐릭터의 응답 읽기
   - 하단의 입력창에 메시지 입력 또는 추천 질문 버튼 클릭
   - 엔터키 또는 전송 버튼으로 메시지 전송
   - 키워드를 포함한 질문으로 다음 단계 대화 진행

5. **다른 캐릭터와 대화**
   - 좌측 상단의 뒤로가기 버튼으로 캐릭터 선택 화면으로 이동
   - 다른 이웃 선택하여 새로운 대화 시작

## 📱 기능 URI

### 메인 경로
- `/` - 이름 입력 화면 (초기 화면)
- 이름 입력 후 - 캐릭터 선택 화면
- 캐릭터 선택 후 - 1:1 채팅 화면

### API 엔드포인트
- `GET tables/characters` - 캐릭터 목록 조회 (5명)
- `GET tables/messages` - 메시지 시나리오 조회 (캐릭터별 3단계)

### 대화 시나리오 구조
각 캐릭터는 3단계 대화로 구성:
1. **1단계**: 초기 인사 및 상황 설명
2. **2단계**: 키워드 기반 심화 대화 (문제점/좋은점 상세 설명)
3. **3단계**: 종료 인사 및 교훈 정리

## 👨‍🏫 활용 안내

### 수업 활용 예시 (45분 기준)

1. **도입 (5분)**
   - 다문화 사회의 의미 설명
   - 활동 목표 제시
   - 앱 사용 방법 간단 안내

2. **활동 (25-30분)**
   - 학생들이 이름 입력 후 개별 활동 시작
   - 5명의 인물과 순차적으로 대화
   - 각 대화에서 발견한 긍정적 효과와 문제점 메모
   - 추천 질문을 활용하거나 자유롭게 질문 작성

3. **정리 (10-15분)**
   - 각 캐릭터와의 대화 내용 공유
   - 발견한 문제점과 긍정적 효과 정리
   - 다문화 사회를 위한 태도 토론

- ✅ 문화적 차이에 대해 공감적 태도로 대화했는가?
- ✅ 긍정적 효과와 문제점을 구분하여 이해했는가?
